sharness.ai

SHarness runs agents and their tools as small, single-purpose processes, each locked down by the kernel and talking only over allowed, mutually authenticated connections. By Dinis Cruz. All content CC BY 4.0.

↗ cli.sgit.ai — sgit, the first harnessed app · ↗ pki.sgit.ai — the handover it builds on · ↗ riskmandate.ai — Agent Behaviour Policies
