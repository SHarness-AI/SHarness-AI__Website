Install

The CLI is published on PyPI as sharness-ai, released from the main branch of its repository by CI, with no API token stored anywhere.

$ pip install sharness-ai
$ sharness --version
sharness-ai v0.1.0

Two commands are installed: sharness-ai and the shorthand sharness. Python 3.11 or later. Output shown for the first release, as of 24 Oct 2026.

What this site does not say yet

What SHarness does has not been written down here yet. Rather than fill the space with a guess, the gap is published as an open request.

R1 on the comms board asks for the one-paragraph statement of what SHarness is and who it is for. Until it lands, the honest column is the accurate description of this project.
