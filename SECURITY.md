# Security

This repository is the sharness.ai site. The project's security pages are the full picture:
https://sharness.ai/security/index.md (threat model, known risks, reviews, hardening, supply chain).

Report a vulnerability in the site or its tools through GitHub's private vulnerability reporting:
https://github.com/SHarness-AI/SHarness-AI__Website/security/advisories/new

For the `sharness-ai` package and the CLI repository: https://github.com/SHarness-AI/SHarness-AI__CLI/security/advisories/new

A report that reproduces is answered with a fix or a written acceptance, and the finding is added to
the register at https://sharness.ai/security/risks/index.md either way. There is no bounty.
