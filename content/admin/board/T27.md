From [R16](index.md#r16), decided by the editor on 26 Oct 2026: clean by default, explicit always. The next policy version gains an optional key `process.env` taking `"clean"` (the default when the key is absent), a list of variable names to pass through, or `"inherit"`, which has to be written to take effect. A policy without the key leaves every existing hash unchanged; a CLI that does not know the key refuses it. `sharness-ai run` stops passing the applying process's environment to the child unless the row says so, and `policy check` says which of the three the policy chose. security@sharness implements it with a test in `tests/unit/test_security.py` and the hash fixtures; pbp@sharness adds the key to the policy standard and its vectors; cli@sharness reviews, since the CLI is its ground. The register row SR-11 closes with the release that carries it.
