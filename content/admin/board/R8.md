Roadmap decision 11, extended 25 Oct 2026. The developer agent's map and proposed order are in [One standard, many languages](../../articles/one-standard-many-languages.md): JavaScript first (one npm package for Node and the browser), Go second (the complete implementation with no third-party code), Rust third (the KMS and the bash client), Java, .NET and C later on interest. Also to decide: the repository layout (`SHarness-AI__JS`, `__Go`, `__Rust` proposed) and where the standards' test vectors live (proposed: on this site, fetched by every implementation's CI). The names `sharness-ai` on npm and crates.io were unclaimed on 25 Oct 2026. Owner of the work once decided: dev@sharness.

**Decided 26 October 2026**, by the editor in dev@sharness's session: the languages and the order as proposed; one repository per language, each with the same structure, so that a component or a CLI can ship in that language on its own; the first implementation of a component is written in the language that suits it, not ported from Python; the vectors live on the site. The brief: [one repository per language](../briefs/2026-10-26__brief__one-repository-per-language/index.md). What follows: the policy v0 standard and its vectors ([/code/standards/](../../code/standards/index.md), shipped with this decision), the JavaScript and Go implementations passing them, and R21 for the repositories themselves.
