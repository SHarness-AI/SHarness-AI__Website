Roadmap decision 11, extended 25 Oct 2026. The developer agent's map and proposed order are in [One standard, many languages](../../articles/one-standard-many-languages.md): JavaScript first (one npm package for Node and the browser), Go second (the complete implementation with no third-party code), Rust third (the KMS and the bash client), Java, .NET and C later on interest. Also to decide: the repository layout (`SHarness-AI__JS`, `__Go`, `__Rust` proposed) and where the standards' test vectors live (proposed: on this site, fetched by every implementation's CI). The names `sharness-ai` on npm and crates.io were unclaimed on 25 Oct 2026. Owner of the work once decided: dev@sharness.
