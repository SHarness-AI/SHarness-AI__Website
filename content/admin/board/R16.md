Register row [SR-11](../../security/risks/index.md#the-register): today `sharness-ai run` passes the whole environment of the applying process to the child, API keys and proxy credentials included, because v0 has no row for it; since 25 Oct 2026 `run` says so on stderr every time and `policy check` in its advice. Proposed for the next policy version: `process.env` taking `"inherit"`, `"clean"` or a list of variable names to pass. A new optional key leaves every existing hash unchanged; a CLI without the key refuses the unknown key, which is the right failure. The designed end state removes most of the need (`sharness.llm` and `sharness.kms` hold the secrets), but the row is cheap and closes a Medium gap now. The editor decides the shape; the security agent implements it with a test and the hash fixtures.
